# Software:
## Steps:
### Download the Raspberry Pi OS (64-bit) model:

Link--> https://www.raspberrypi.com/software/operating-systems/

Scroll down to the Raspberry Pi OS (64-bit) and press download button next to "Raspberry Pi OS"

### Uploading the OS to tablet:

Download Raspberry Pi Imager

Attach SD card that is going to be used for the Tablet (Min 64gb)

Open app and select downloaded OS file and write to the attached SD card.

When finished, disconnect the SD card.

Then, connect the SD card to the Tablet and power on.
