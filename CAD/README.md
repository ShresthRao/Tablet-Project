# CAD Files
## 3D print:stl files
These files are only for 3D printing, consisting of files for the top and bottom case. Any changes to source files would mean that these stl files need to be exported again.
## Assembly
These files are the assembly file in two formats (.f3z and .step). It is a file consisting of the top case, bottom case and 3D PCB model all put together.
## Source files
### Bottom_Case
These files are the files related to the bottom case 3D model in two formats (.f3z and .step) and are used to edit the 3D model yourself.
### PCB_3D model
These files are the files related to the PCB 3D model in two formats (.f3z and .step) and are used to edit the 3D model yourself.
### Top_Case
These files are the files related to the top case 3D model in two formats (.f3z and .step) and are used to edit the 3D model yourself.
